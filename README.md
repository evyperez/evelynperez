# Evelyn Perez Portfolio

Multilingual professional portfolio built with [Hugo](https://gohugo.io/) and SCSS. It is available in English, Portuguese (Portugal), Portuguese (Brazil), and Spanish.

## Requirements

- [Hugo](https://gohugo.io/installation/)
- Node.js 18 or later
- npm

## Run Locally

```bash
npm install
npm start
```

Open `http://localhost:1313` in your browser.

## Production Build

```bash
npm run build
```

The static website is generated in `public/`.

## Project Structure

```text
assets/       JavaScript and SCSS source files
content/      Localized pages and blog posts
i18n/         Interface translations
layouts/      Hugo templates and reusable partials
static/       Images and generated CSS
config.yaml   Hugo configuration
```

## Customize

- Update contact information and social links in `config.yaml`.
- Edit localized site content in `content/` and labels in `i18n/`.
- Update styles in `assets/stylesheets/`.
- Add project images in `static/images/` and reference them from the relevant template.

# Portfólio Evelyn Perez

Portfólio profissional multilíngue criado com [Hugo](https://gohugo.io/) e SCSS. Está disponível em inglês, português de Portugal, português do Brasil e espanhol.

## Requisitos

- [Hugo](https://gohugo.io/installation/)
- Node.js 18 ou superior
- npm

## Executar Localmente

```bash
npm install
npm start
```

Abra `http://localhost:1313` no navegador.

## Build de Produção

```bash
npm run build
```

O site estático é gerado em `public/`.

## Estrutura do Projeto

```text
assets/       Ficheiros-fonte JavaScript e SCSS
content/      Páginas e artigos localizados
i18n/         Traduções da interface
layouts/      Templates Hugo e componentes reutilizáveis
static/       Imagens e CSS gerado
config.yaml   Configuração do Hugo
```

## Personalização

- Atualize os contactos e links sociais em `config.yaml`.
- Edite o conteúdo em `content/` e os textos de interface em `i18n/`.
- Atualize os estilos em `assets/stylesheets/`.
- Adicione imagens de projetos em `static/images/` e referencie-as no template correspondente.
